# ChessDesk v0.2.0

Released 2026-09-30.

This release adds substantial improvements to session management, dashboard
exploration, invoice corrections, and account recovery, alongside security and
deployment hardening.

## Highlights

- **Group coaching:** Schedule one shared session for multiple students, choose
  between Students and School when booking, and review a client's session
  history.
- **Dashboard drill-downs:** Open activity counts to inspect active students,
  active schools, completed and upcoming sessions, and unpaid invoices.
- **Invoice corrections:** Return an invoice marked paid to unpaid. This clears
  its recorded payment date, method, and reference; it does not issue a refund
  through a payment processor.
- **Password recovery:** Coaches can receive a single-use password-reset link
  by email. Links expire after 30 minutes, and the request endpoint does not
  reveal whether an account exists. Email delivery uses Resend; see the
  [configuration guide](https://github.com/Eleazarovich/chessdesk/blob/main/backend/README.md#password-reset-email).
- **Security and operations:** Add authentication rate limits and request
  bounds, expire legacy login sessions, secure invoice exports, and strengthen
  CloudFront-to-origin TLS and deployment role boundaries. Production deploys
  now require the protected GitHub environment approval and include a health
  check with container rollback on failure.
- **Updated demo data and visuals:** Refresh the seeded example records and
  screenshots.

## Upgrade notes

- Existing coach accounts and business records are preserved. The authentication
  migration expires existing login sessions once, so coaches may need to sign
  in again after upgrading.
- Password-reset delivery requires a Resend API key, verified sender, and public
  app URL. The hosted deployment supplies its sender and site URL; configure the
  Resend key as described in the backend setup notes.
- Session-change notification records remain in the app, but email and WhatsApp
  delivery for session notifications is not connected.
